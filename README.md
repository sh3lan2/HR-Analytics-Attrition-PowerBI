# 👥 HR Employee Attrition & Analytics Dashboard

An interactive Power BI dashboard designed to analyze employee turnover, identify key drivers behind staff attrition, and evaluate workforce demographics across job roles and departments.

## 🛠️ Tech Stack & Key Features
- **Business Intelligence:** Power BI Desktop (DAX Measures, Dynamic Slicers).
- **KPI Metrics:** Total Employees, Active Count, Attrition Rate %, and Average Age.
- **Key Analysis Areas:** Turnover by Department, Overtime Impact, Job Satisfaction Levels, and Tenure.
